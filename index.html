What Is Semantic HTML?

Semantic HTML uses meaningful elements to describe the purpose of different parts of a web page.

Examples include header, nav, main, section, article, and footer.

Why Am I Learning HTML?

HTML provides the structure of a web page. Semantic HTML helps describe the meaning of its content.
