# Day 01 - HTML Foundations & Semantic Structure

## Project Overview
This project demonstrates the fundamentals of HTML5 and the use of semantic HTML elements.

## Pages

- **index.html:** The homepage, including learning goals and examples of semantic HTML.
- **profile.html:** A personal profile page containing biography, education, training, experience, achievements, and contact information.

## Technologies
- HTML5
- Semantic HTML

## Key Concepts
- HTML document structure and metadata
- Headings, paragraphs, and lists
- Links and images
- Semantic elements such as `header`, `nav`, `main`, `section`, `article`, and `footer`

## How to Run
Open `index.html` in a web browser and use the navigation links to visit the profile page.
